# Psymod Library — Psychology SaaS Platform

WordPress plugin for a psychology platform with a content library of 5000+ materials, membership system and payments.

## Features
- 5000+ psychology materials and resources
- Multi-level access control (free, basic, premium)
- Personal user dashboard
- Payment integration
- Content categorization and search

## Stack
- PHP
- WordPress
- MySQL

## Installation
1. Upload plugin to /wp-content/plugins/psymod-library
2. Activate via WordPress admin panel
3. Configure access levels and payment settings
